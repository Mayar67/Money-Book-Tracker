# دفتر فلوسي

دفتر شخصي لتسجيل المصروف والدخل والحوشة. صفحة واحدة من غير سيرفر.

- كل حد بيعمل دفتر باسم ورقم سري (PIN) على الجهاز بتاعه.
- البيانات بتتحفظ في المتصفح بس (localStorage)، ومش بتتبعت لأي مكان.
- بيشتغل كتطبيق من الشاشة الرئيسية (PWA) ومن غير نت بعد أول فتحة.

## النشر على Vercel
1. ارفعي الملفات دي على repository في GitHub.
2. من vercel.com: Add New → Project → Import الـ repository → Framework Preset: Other → Deploy.

أي تعديل تعمليه بعد كده في الملفات على GitHub، Vercel بينشره لوحده.
