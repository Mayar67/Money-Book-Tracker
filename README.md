# دفتر فلوسي

دفتر شخصي لتسجيل المصروف والدخل والحوشة. صفحة واحدة (PWA) منشورة على Vercel.

- كل حد بيعمل حساب بالإيميل والباسورد، ودفتره بيتحفظ أونلاين (Supabase) ويظهر على أي جهاز يدخل منه.
- كل صف في قاعدة البيانات مربوط بصاحبه، وسياسات Row Level Security بتمنع أي حساب يشوف أو يعدّل بيانات حساب تاني.
- بيتثبت كتطبيق من الشاشة الرئيسية.

المفتاح الموجود في `index.html` هو مفتاح Supabase العام (anon) المعمول عشان يتحط في التطبيق؛ الحماية جاية من سياسات RLS.
